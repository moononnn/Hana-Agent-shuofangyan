# 说方言（Hana v2 应用）

给每位伙伴挑一口家乡味。

挑上，ta 打字就带上那个味儿，下一条消息就听得出来；不想听了点一下撤掉，人格文件回原样，不留痕迹。

九种方言：东北话、四川话、粤语、上海话、台湾腔、北京话、河南话、陕西话、新疆话。另有一个「学我说话」，不给口音，照着你的打字习惯来。

## ⚠️ 用之前先知道这些

### 1. 【最重要】这个应用会改你伙伴的人格文件

挑口音这个动作，会往那位伙伴的 `agents/<id>/AGENTS.md` 里写一段设定。

具体是这么写的：

- 用注释标记圈起来，**只动这一小段**，你自己写的内容一个字节都不碰；
- **不点就永远不写**。装上应用、打开看一眼都不会改任何东西；
- 取消口音，整段删掉，文件回到原样，不残留空行和标记；
- 第一次进这个应用会先弹一张确认卡，把上面三条摊开讲一遍，你点过「知道了，开始挑」它才肯动手。后端也拦了一道，没确认过的保存请求直接拒掉。

我知道「改人格文件」听起来重。这个应用的判断很简单：口音属于「ta 是谁」的一部分，放进人格文件每轮都在，不额外吃上下文，长对话也不会被挤掉；换成每轮拼一段提示词，聊久了就可能丢。所以选了写文件这条路，但把它做成你亲手点、随时能撤、界面上明说有后果的样子。

### 2. 写完不用重启

这一点跟早期的做法不一样：写完下一条消息就带味儿了，不用关掉 Hana 再开。

想让它更干净，开个新对话。旧对话里已有的上下文还带着之前那些话，模型有时候会沿用。

### 3. 效果看模型，别指望装上就百分百像

写进去的是一段说话习惯的提示词，不是给 ta 装了个语音包。

同一个方言，不同模型出来的味道差别很大：有的会自然地蹦家乡词，有的只学个句尾语气词。文案本身做过收敛，新疆话那种资料少、可选词少的，我在文案里直接标了「效果一般」，不粉饰。

### 4. 这是说话习惯，不是给 ta 换个脑子

注入的文案里明确写了「做正事时别受这个影响」。实际测下来日常聊天很自然，但我没有测正经写代码、写分析这种场合——我自己用不到，就不假装测过。

如果你把 Hana 当纯生产工具使，建议别开，或者只给聊天用的那位开。

### 5. 「学我说话」会读你们的聊天，还会调模型

这条链路单独说清楚：

- 只取**你自己说的话**，不取伙伴的；
- 默认读全部伙伴的会话，可以在「语料来源」里改成只看某一位，或在名单里把某几位隐藏掉（隐藏会同时影响这里）；
- 调用宿主的模型通道做总结，会消耗额度。用哪台模型可以自己选；
- 总结出来的是一份草稿，你不点「采用新版」它就不会写进人格；
- 每次总结都留一版，一共留 10 版，新版和当前版并排给你看，改坏了随时「恢复这版」。

### 6. 隐私与权限

| 能力 | 为什么需要 |
| --- | --- |
| `app/agents.read` | 列出宿主里的伙伴（不然界面上只有一串英文 id） |
| `app/resources.read` | 读伙伴的人格文件与他们的会话记录（App 沙箱读不到宿主目录，正门是这条通道） |
| `app/resources.write` | 把方言块写进人格文件 |
| `app/models.infer` | 「学我说话」要调模型做总结 |
| `app/tools.expose-to-model` | 给模型一个查自己现在什么口音的小工具 |
| `app/services.provide` | 让表情包应用来问「这位伙伴现在什么口音」（见下方联动一节，可以不给） |

- 口音配置、风格模板、确认记录都存在本机的应用数据目录（`app-data/shuo-fangyan`），不上传；
- 读宿主资源每次都会被盖章记审计，日志在宿主的管理界面里能看到；
- 会话也是走资源通道读的（`agents/<id>/sessions/`），所以没有另外要一项读会话的权限；
- 应用自己不发任何网络请求，所有外部通信都走宿主通道，出不出得去由 Hana 的放行规则决定。

## 安装

Hana v2 应用，装法跟其他同类应用一样：

1. 打开 **应用管理** → 导入本地应用（装包 ZIP，或直接指向这个目录）；
2. 按提示逐项允许权限，界面上给的中文名大概是：读伙伴列表、读写宿主资源、调用模型、把工具开给伙伴、提供服务给其他应用；
3. 装好后在应用管理里能找到「说方言」，点开就是口音小册（它不占左侧导航，免得日常侧边栏多一格）。

第一次打开会先看到那张确认卡，读完点「知道了，开始挑」就进去了。

## 卸载

应用管理里卸载就行。配置和模板留在 `app-data/shuo-fangyan`，不会跟着删；要清干净就卸载后手动删掉那个目录。

**卸载前记得把口音撤掉**。人格文件里那段是应用自己写的、也由它自己删，卸载了没人替你收尾。真忘了，手动打开 `agents/<id>/AGENTS.md`，删掉 `<!-- shuo-fangyan-dialect:start -->` 到 `:end -->` 之间那几行，一样干净。

## 它能做什么

### 🗣️ 九种方言，一位伙伴一口

东北话、四川话、粤语、上海话、台湾腔、北京话、河南话、陕西话、新疆话。

一位伙伴挑一种，互不影响。九宫格摆在那儿，点哪格就是哪格，没有保存按钮，点完就写进去了。

每种方言一档文案：带句式示范、常用词表和句尾语气词。同一套文案，不同模型表现不一样，这是提示词本身的脾气，不是应用能完全控制的。

### ✋ 不想听了，点一下就撤

点开某位伙伴，最上面那行写着「当前：台湾话 · 取消口音」，点「取消口音」就撤了。

撤掉是整段删，不是留个空壳。人格文件回到你没装这个应用之前的样子。

### 📖 学我说话

读你在这个伙伴会话里说过的话，总结出一段「你怎么打字」的描述，让 ta 照着来。

总结完先出草稿，左边是现在用的版本，右边是新草稿，你比对着看，觉得好才点「采用新版」。每次总结都留一版，一共 10 版，随时能回退。

觉得哪一版不如以前，从「历史版本」里挑出来对比，点「恢复这版」就回去了。

### 👀 不想看的那几位，藏起来

名单里伙伴多了会有点挤。点「隐藏这位伙伴」，它就从这个列表里收起来，放进底下的「已隐藏」，随时能「放回名单」。

隐藏只影响这个应用的显示，**不动 ta 的口音，也不动人格文件**。藏起来的伙伴照样带着味儿说话。

### 🎭 和表情包之间有一条细线（可选）

装了表情包应用的话，它选图时会来问一句「这位伙伴现在什么口音」，拿到气质权重就在候选图里重新排序：东北话偏搞笑，上海话偏温和。

这条通道是这个应用**提供**、表情包**来问**，单向只读。不给 `app/services.provide` 也不影响任何核心功能，只是表情包那边会当「没开方言」，发图流程照常。

说句实话：这个联动存在，但**弱**。模型配图时多数时候只给一个情绪词，那种情况下所有同类图乘同一个系数，名次一点不动；只有它同时判断出两种情绪（比如又开心又想闹）才会真的换几张。所以我没把它当卖点写，你也不必为了它去开权限。

## 界面一览

一个页面，两个页签。

**伙伴口音**：一行一位伙伴，点开是九宫格。已经挑过的，展开区顶上第一行就写着当前是什么口音，右边跟着「取消口音」。

**学我说话**：上面选语料来源，中间并排两栏（当前版 / 新草稿），下面才是「采用新版」「恢复这版」和「历史版本」。

## 第一次使用

1. 打开应用，看完确认卡，点「知道了，开始挑」；
2. 名单读出来后，挑一位想让它带口音的伙伴，点开那行；
3. 九宫格里点一个方言。点完就写进去了；
4. 去跟 ta 说句话，下一条回复就该带味儿了。

不满意就回来，点开同一行，点「取消口音」，再换一个。

## 为什么做这个应用

方言这个东西，最早是塞在表情包应用里的一个附属页。

后来发现不对劲：表情包管的是「心情」，管的是「什么时候贴一张图」；方言管的是「ta 怎么说话」。两件不相干的事，硬塞在一个应用里，功能面板越长越杂，权限也被拖着一起放大——为了一个口音，得让整个表情包应用拿着写人格文件的权限。

拆出来的道理跟抽屉一样：一个抽屉只放一类东西，权限也只开给真正需要它的那个。表情包现在一个字都写不进人格，只管图；要说方言，来这里挑。
