# 说方言

给每个伙伴挑一口家乡味。挑上就写进 ta 的人格文件，ta 打字自然带那个味儿；取消即移除，不留痕迹。

## 它做什么

- **九种方言**：东北话、四川话、粤语、上海话、台湾腔、北京话、河南话、陕西话、新疆话。
  每种只有一档文案（配置 v4 起）：精修版，带句式示范和语气词表，「加浓」那个两档开关已经取消。
- **按伙伴开关**：点一下口音就写进人格，再点一下取消，没有保存按钮。
- **「学我说话」**：读你在这个伙伴会话里说过的话，调用模型总结成一段风格描述，
  让伙伴照着你的打字习惯来。总结完先给草稿，你点头才采用，还能回退上一版。
- **写人格文件**：方言以标记块的形式写进 `agents/<id>/AGENTS.md`，
  只动自己那一段，你自己在设置里写的内容不会被碰。

## 权限说明

| 能力 | 为什么需要 |
| --- | --- |
| `app/agents.read` | 列出宿主里的伙伴（带显示名），不然界面上只有英文 id |
| `app/resources.read` | 读伙伴的人格文件与他们的会话记录（App 沙箱读不到宿主目录，正门是这条通道） |
| `app/resources.write` | 把方言块写进人格文件 |
| `app/sessions.read` | 「学我说话」要读会话里的用户发言 |
| `app/models.infer` | 「学我说话」要调模型做总结 |
| `app/tools.expose-to-model` | 给模型一个查自己方言的小工具 |
| `app/services.provide` | 让表情包应用来问「这位伙伴现在什么口音」，好在选图时跟着气质走 |

每次读宿主资源宿主都会盖章并记审计，日志在宿主的管理界面里能看到。

## 与表情包应用的联动

伙伴开了方言之后，表情包选图会按这份口音的气质权重重新打分（东北话偏搞笑、上海话偏温和，等等）。
权重表只在本应用存一份，表情包不自己拷贝。

通道是宿主 bus 上的一个只读服务：

- 本应用注册 `app:shuo-fangyan/dialect-bias`（需 `app/services.provide`，带 `allowCrossApp`），
  入参 `{ agentId }`，返回 `{ dialect, name, label, bias }`；没开方言时 `bias` 为 `null`。
- 表情包持 `app/services.call` 来问，结果缓存一分钟，失败缓存十秒。
- 没装本应用、没授权、对方没启动或超时，一律静默降级成「没有方言气质」，发图流程照常走。

宿主会给每次调用盖章 `callerAppId`，这边看到的是「谁在问」，不是对方自报的名字。
